# 材料株ニュース監視 — スマホ対応版

この版はスマホのブラウザから使うことを前提に調整しています。

## 一番簡単な使い方：Streamlit Community Cloud
1. このフォルダの `app.py` と `requirements.txt` を GitHub の同じリポジトリに置く
2. Streamlit Community Cloud に GitHub でサインイン
3. `Create app` を押す
4. Repository を選択
5. Main file path に `app.py` を指定
6. Deploy
7. 発行された `https://xxxxx.streamlit.app/` をスマホで開く

以後はスマホ側にPythonのインストール不要です。
ホーム画面に追加すれば、アプリのように起動できます。

## Androidでホーム画面に追加
Chromeで公開URLを開く → 右上の︙ → 「ホーム画面に追加」
